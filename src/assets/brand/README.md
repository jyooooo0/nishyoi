# ブランド素材の置き場

ここにロゴ画像を置く。

- `logo-text.(png|svg)` — 手書きの屋号ロゴタイプ「仁兵衛家」(横組み)
- `logo-mark.(png|svg)` — 屋号紋「鉤(かね)にイ」の筆線マーク

背景透過のPNG(できれば長辺2000px以上)またはSVGを推奨。

## 使い分け(2026-07-18 決定)

- ファビコン: マーク(鉤にイ)。実ファイルが届くまでは public/favicon.svg に清書版を仮置き
- ヘッダー左上: 可読性を優先して当面は欧文「NISHYOI」のまま。
  実ファイルが届いたら、マークを小さく添える案を試す(手書き漢字は小サイズで潰れるため)
- 手書きロゴタイプ「仁兵衛家」: ヒーロー付近またはフッターの署名的な位置に使用
- 屋号の正式表記は「仁兵衛(にへえ)」(人偏に二の「仁」)
