## プロジェクトの目的

NISHYOIは、山形県鶴岡市関川の山間集落を拠点に、里山の知恵と現代のテクノロジーを組み合わせ、暮らし続けられる形を試す活動です。

中心となる考え方は次のとおりです。

> 消えゆく可能性のある集落の時間を記録しながら、古くからの知恵と新しい技術を手がかりに、新しい暮らしを育てる。試みが成功すれば暮らしのモデルとなり、集落がなくなった場合にも記録がアーカイブとして残る。

サイトは単なる田舎暮らしブログや観光案内ではありません。丈本人のプロフィールと思想、イベントへの参加、暮らしと技術の記録、Web制作の仕事、将来の商品販売を一つの世界観にまとめる公式サイトです。

## デザインの方向性

参考サイトはSuuHaaですが、HTML、CSS、画像、文章、ロゴ、イラスト、細部の演出をコピーしてはいけません。参考にするのは次の設計原則です。

- 大きな写真と短い言葉で世界観へ入れる。
- セクションごとに背景色、余白、写真比率、文字位置を変え、単調なカードの連続を避ける。
- 左右非対称のレイアウト、写真の重なり、縦書きまたは縦方向のアクセントを適所で使う。
- 一覧性だけでなく、スクロールすることで風景を歩くようなリズムを作る。
- 見出し、番号、季節名、二十四節気などを編集的なグラフィック要素として使う。
- 写真家が運営するサイトとして、写真を小さなサムネイルへ閉じ込めない。
- 伝統的な和風記号を多用せず、現代の技術が共存できる端正なデザインにする。
- 観光サイト、高級旅館、量産的な田舎Vlog、一般的なSaaSサイトに見せない。
- KOTOGRAPHとは作家性を共有しても、ポートフォリオの複製にはしない。

## 動きの要件

動きは装飾ではなく、時間、季節、作業のリズムを伝えるために使ってください。

### 採用候補

- ファーストビュー写真のごく緩やかなスケールまたは視差
- スクロールに合わせた見出し・写真の控えめなフェードと移動
- セクション間をつなぐ川のような線や季節インジケーター
- Journalカードのずれたタイミングでの出現
- 写真のクリップ、マスク、重なりがほどける演出
- イベントカードの残席・受付状態の穏やかな変化
- リンクの下線や矢印が伸びるホバー
- 二十四節気のゆっくりした横移動または現在位置表示
- ページ遷移時の短いフェード

### 禁止・抑制

- スクロールジャック
- 強制的な横スクロール
- 長いローディング演出
- 常時動き続けて文章を読みにくくする装飾
- 大量のパララックス
- カーソル追従を主要操作にすること
- モバイルで重い動画や巨大JavaScriptを読み込むこと
- 同じフェードアップを全要素へ機械的に付けること
- アニメーションのためだけに大規模ライブラリを追加すること

### アクセシビリティ

- `prefers-reduced-motion: reduce` では、視差、自動移動、スケール、連続アニメーションを停止する。
- アニメーションがなくても全情報と操作を利用できるようにする。
- 動きによってレイアウトシフトを起こさない。
- キーボードフォーカスを明確にする。
- コントラストはWCAG 2.2 AAを目標にする。

## 写真の扱い

- 仮画像を外部の無関係なストック写真で埋めない。
- 現在のリポジトリにある写真を棚卸しし、使用可能な素材を一覧化する。
- 不足画像は、必要な構図、季節、縦横比、解像度を撮影リストとして提示する。
- ファーストビューは関川集落の横長写真を想定する。
- 丈のプロフィールには正面写真だけでなく、撮影・薪割り・山仕事など活動中の写真も候補にする。
- 画像ごとに焦点位置を指定できるようにする。
- AVIF/WebP、`srcset`、遅延読み込みを使い、LCP画像だけは適切に優先する。
- EXIFの位置情報を公開しない。
