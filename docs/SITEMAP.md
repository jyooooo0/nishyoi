# NISHYOI サイトマップ案

- バージョン: 0.1
- 作成日: 2026-07-16
- ステータス: ヒアリング途中の初期案

## 1. 基本方針

トップページでは、関川集落の写真と丈の言葉を通じて「誰が、どこで、なぜ活動しているか」を伝え、現在参加できるイベントへ案内する。暮らしの詳細、技術検証、制作実績、将来の商品販売は下層へ分ける。YouTube開始後は映像を主要導線に加える。

### 優先順位

1. 丈のプロフィールとNISHYOIの思想
2. イベント告知、申込み、予約管理
3. 暮らしと実験の記録
4. Web制作の実績と依頼窓口
5. YouTube開始後の映像導線
6. 販売体制が整った後の山菜・卵・写真作品等の販売

## 2. 全体構造

```text
/
├─ /about/                         NISHYOIについて
│  ├─ /about/jo/                   丈のプロフィール
│  └─ /about/sekigawa/             関川集落について
├─ /events/                        イベント一覧
│  └─ /events/[slug]/              イベント詳細・申込み
│     └─ /events/[slug]/complete/  申込み完了
├─ /journal/                       暮らしと実験の記録
│  ├─ /journal/[slug]/             記事詳細
│  ├─ /journal/season/             季節・二十四節気（将来）
│  └─ /journal/category/[name]/    カテゴリー別（将来）
├─ /films/                         映像一覧（YouTube開始後）
│  └─ /films/[slug]/               映像と背景記事（将来）
├─ /works/                         Web制作・地域事業支援
│  ├─ /works/web/                  Web制作サービス
│  └─ /works/[slug]/               制作実績詳細
├─ /shop/                          季節のもの・作品（販売開始後）
│  ├─ /shop/eggs/                  卵
│  ├─ /shop/wild-food/             山菜・きのこ・加工品
│  ├─ /shop/photographs/           写真作品
│  └─ /shop/[slug]/                商品詳細
├─ /contact/                       問い合わせ
├─ /privacy/                       プライバシーポリシー
├─ /terms/                         利用規約・イベント規約
└─ /commercial-law/                特定商取引法表記（販売開始後）
```

英語版は対応する `/en/` 配下に置く。初期はHome、About、Journalを優先し、地域イベントは対象に応じて日本語のみでもよい。

## 4. ページ別掲載情報

### 4.1 Home `/`

掲載順:

1. 関川集落の大きな写真、ロゴ、一文のコンセプト
2. 集落、記録、暮らしの実験を説明する短いステートメント
3. 募集中イベント（最大3件）
4. 暮らしの入口
   - 季節と手仕事
   - 動物と暮らし
   - 田舎とテクノロジー
   - 集落の記録
5. Journal最新3〜6件
6. 丈の短い紹介と詳細プロフィールへの導線
7. Web制作の短い案内と実績への導線
8. 最新YouTube動画（開始後）
9. 販売中の商品（販売開始後）
10. Contact、KOTOGRAPH、SNS、規約類

暫定コピー:

> 山形の山あいにある、生まれ育った集落。  
> なくなるかもしれないこの場所で、私はもう一度、暮らしをつくり始めます。  
> 古くからの知恵と新しい技術を手がかりに、その過程を記録します。

### 4.2 NISHYOIについて `/about/`

- NISHYOIという屋号
- 集落がなくなるかもしれないという問題意識
- 記録するだけでなく、暮らすことで残る可能性を探す理由
- 里山の知恵とテクノロジーを組み合わせる方針
- 成功すれば暮らしのモデル、失敗してもアーカイブになるという考え
- 現在の取り組み
  - 家庭菜園、山菜、薪割り、雪かき
  - 受精卵から始めるニワトリの飼育
  - 将来のヤギ飼育
  - 衛星データとAIを用いた舞茸候補地の探索
  - 二十四節気のフォトウォーク
  - 暮らしのオープンデイ
  - 写真、映像、Webによる発信と仕事づくり
- 丈、関川集落、KOTOGRAPHへの導線

### 4.3 丈のプロフィール `/about/jo/`

- 五十嵐 丈 / Jo Igarashi
- 1993年、山形県鶴岡市関川生まれ
- 大学進学で地域を離れた経験
- 銀行勤務
- 自然体験、しな織・しなの花の地域事業へ携わった経歴
- 上記プロジェクトからは現在離れていること
- 現在は写真家として活動していること
- 暮らしを起点にNISHYOIを始めたこと
- KOTOGRAPH、Web制作実績へのリンク
- 本人または活動中の写真

初期は「私＝丈」で語る。妻を共同運営者として先回りして掲載せず、参加後に追加できる構造にする。

### 4.4 関川集落 `/about/sekigawa/`

- 山形県鶴岡市の山間集落であること
- 雪、川、山、季節の風景
- しな織など受け継がれてきた文化
- 人口減少と集落存続の課題
- 丈が撮影した集落写真
- 関連Journal記事

変動する数値には基準日と出典を付ける。住民、私有地、生活動線が特定される情報は必要性を確認する。

### 4.5 Events `/events/`

- 受付中、受付予定、終了したイベント
- 二十四節気のフォトウォーク
- オープンデイ
- その他の季節体験
- 初参加者向け案内
- キャンセル、安全、撮影の基本方針

### 4.6 Event詳細 `/events/[slug]/`

- 名称、趣旨、日時、所要時間
- おおよその地域と集合場所の通知方法
- 当日の流れ、対象者、対象年齢、定員、残席
- 料金（現時点の想定は3,000円程度。イベントごとに確定）
- 持ち物、服装、雨天対応、キャンセル規定
- 写真撮影・掲載への同意
- 安全、動物、山林に関する注意
- 申込みフォーム

予約状態は「下書き、受付予定、受付中、満席、受付終了、中止、終了」を持つ。予約基盤は既存の `C:\Users\jmfs2\projects\nua` の再利用可否を別途調査する。

### 4.7 Journal `/journal/`

カテゴリー:

- 季節と手仕事
- 動物と暮らし
- 田舎とテクノロジー
- 山の恵み
- 集落の記録
- 写真と映像

二十四節気、ニワトリ、舞茸などはタグで管理する。カードには写真、タイトル、日付、カテゴリー、二十四節気、概要を表示する。

### 4.8 Journal詳細 `/journal/[slug]/`

- タイトル、リード、公開日、更新日
- 季節、二十四節気
- 写真、本文
- 使用した技術・道具
- 結果と失敗
- YouTube動画（開始後）
- noteの詳細記事（ある場合）
- 関連記事

山菜・舞茸探索は方法を公開しても、正確な座標、採取地点、特定可能な地形は公開しない。

### 4.9 Films `/films/`（YouTube開始後）

- 最新動画、長編動画一覧、YouTube登録導線
- シリーズ
  - ニワトリが生まれ、群れになるまで
  - 二十四節気と手仕事
  - 田舎とテクノロジー
  - 集落の記録

埋め込みは遅延読み込みとし、音声を自動再生しない。

### 4.10 Web制作 `/works/web/`

対象:

- 庄内の小規模事業者、店舗、作家、地域プロジェクト
- 全国の過疎地域で、小さな事業や発信を始める個人・団体

掲載情報:

- 地域や事業の魅力整理
- 写真撮影
- 文章・情報整理
- Web制作
- 予約、販売、問い合わせ導線
- 制作の流れ
- 実績3〜5件
- FAQ、問い合わせ
- 将来の料金目安

初期は制作・実装を中心にし、相談だけを独立商品にしない。

### 4.11 制作実績 `/works/[slug]/`

- プロジェクト名、完成画面、公開URL
- 課題、担当範囲、写真撮影の有無
- 実装機能、使用技術
- 制作後の変化・成果
- 許可がある場合はクライアントコメント

名称、画面、URL、成果の掲載許可を得た案件だけ公開する。

### 4.12 Shop `/shop/`（販売開始後）

- 卵
- 山菜・きのこ・加工品
- 写真作品
- デジタル商品
- 販売中、入荷待ち、季節終了の状態

商品詳細には価格、数量、背景、生産時期、在庫、配送・受取、保存方法、注意事項、法定表示を載せる。販売開始前に採取権限、衛生、食品表示、営業許可、配送、返品条件を確認する。

### 4.13 Contact `/contact/`

問い合わせ種別:

- イベント
- Web制作
- 写真・取材・協業
- 商品（販売開始後）
- その他

入力項目は、名前、メール、組織名（任意）、種別、本文、プライバシーポリシー同意。

## 5. 既存ページの扱い

| 既存ページ | 新構成での扱い |
|---|---|
| `/about/` | 再編集して継続 |
| `/journal/` | カテゴリーを再設計して継続 |
| `/food/` | 販売開始後に `/shop/wild-food/` へ再編 |
| `/life/` | Journal「動物と暮らし」へ再編 |
| `/tea/` | Journalまたは商品詳細へ再編 |
| `/rasendo/` | 宿泊を当面行わないためナビから外す。削除・アーカイブ・転用は別途判断 |

既存URLに外部流入がある場合は、新URLへリダイレクトする。
